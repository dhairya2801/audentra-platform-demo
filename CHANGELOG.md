# Changelog

This changelog summarizes user-visible releases. Detailed notes are separated
by persona so students, staff, and implementation teams can review only the
changes that affect them.

## 2026-08-10 — Action Center lifecycle hardening

### Reliable intelligence

- Verified `openai/gpt-5.6-luna` and `openai/gpt-5.6-luna-pro` now use strict
  OpenRouter JSON Schema for Action Center enrichment and supported document
  extraction. The server continues to normalize and validate every response.
- Communication activity is coalesced by interaction source version behind a
  five-minute quiet window, with a bounded maximum delay. A later message wins
  over an in-flight stale summary instead of creating duplicate AI jobs.
- One interaction-enrichment response persists the outcome summary,
  conversation signals, and canonical student-summary revision from the same
  bounded evidence snapshot.

### Durable handoffs

- Portal replies, staff portal messages, transcript recovery, interaction
  completion, and transcription completion now make their canonical changes
  before queuing downstream intelligence or notifications.
- Email-provider and telephony-provider integration remain explicit ingress
  boundaries: external inputs must first become durable inbox or recording
  records, so provider retries cannot duplicate CRM work or lose evidence.

See [Action Center lifecycle hardening](docs/changelog/2026-08-10-action-center-lifecycle-hardening.md).

## 2026-08-10 — Calm, grouped student updates

### Students

- Enrollment and onboarding changes now arrive in one grouped, accessible
  portal-visit dialog instead of a sequence of route-change interruptions.
- Choosing **Remind me later** defers the whole displayed set and keeps it out
  of the way until a new portal visit or a return after five minutes inactive.

### Data integrity

- Added an atomic, version-checked batch defer operation so a reminder decision
  cannot leave a mixture of saved and unsaved updates.

## 2026-08-10 — Journey and form template runtime

### Staff-authored journeys

- Added canonical validation and persistence for versioned multi-page forms
  generated by the portal's journey and form scaffold libraries.
- Added answer-driven `all`/`any` route rules for checkbox, single-choice,
  multiple-choice, and bounded number decisions, including switch cases,
  default paths, numeric thresholds, and safe skipped-branch convergence.
- Preserved expected-version publication, dependency-cycle validation, stable
  requirement IDs, and active-student reconciliation for scaffolded graphs.

### Students

- Added server-side validation across every page of a configured form while
  retaining the existing single-page contract for older configurations.
- Student answers now activate only the matching path; unselected paths become
  Not applicable without deleting evidence or awarding completion rewards.
- Kept custom onboarding and enrollment actions on the same durable requirement
  response, notification, reward, audit, and dependency-unlock path.

### Staff realtime updates

- Scheduled follow-up, blocked-review, and overdue-SLA transitions now publish
  realtime events as soon as the canonical notification is created.
- AI enrichment events identify their work item and purpose, allowing the
  portal to distinguish refreshed guidance from a newly submitted inquiry.

See [Detailed journey-template changelog](docs/changelog/2026-08-10-journey-template-runtime.md).

## 2026-08-10 — Durable tenant content management

### Students

- Added persistent Campus Life event registration with duplicate, stale,
  inactive, past-event, reschedule, and cancellation handling.
- Added notifications when a registered event changes or is cancelled while
  preserving canonical refresh behavior for the page itself.
- Added optional staff-curated course videos to informational Classrooms course
  details.

### Staff

- Made Campus Life events and clubs, academic courses, Knowledge Base cards,
  and Core Plays durable, tenant-scoped, versioned database content.
- Added audited CRUD and publication events without coupling deterministic
  content updates to an LLM.

### Data and lifecycle safety

- Added stable source identities, event-version checks, serialized registration
  writes, soft retirement, registration history, and affected-student messages.
- Added bounded HTTPS YouTube metadata validation and nullable per-course media.

See [Detailed content-management changelog](docs/changelog/2026-08-10-content-management-functional.md).

## 2026-08-09 — Functional enrollment action center

### Students

- Added requirement-linked help requests with a visible `Help requested` state.
- Preserved every uploaded original while making transcript parsing retryable.
- Added automatic student updates when a transcript is parsed, reviewed, or
  recovered after a parsing failure.

### Staff

- Added durable work-item creation, assignment, priority, comments, interactions,
  outcomes, follow-ups, history, and configurable deterministic action rules.
- Added immediate inquiry and document-review notifications with team and owner
  routing, plus a resumable tenant-scoped realtime event stream.
- Added automatic human-review tasks for transcript failures and automatic
  resolution when a student later supplies a valid document.

### AI and background processing

- Added quiet-window action enrichment that produces task, outcome, and student
  summaries from one bounded canonical context instead of one LLM call per event.
- Added OpenRouter multimodal transcript extraction and independent durable call
  transcription with retry and failure visibility.
- Kept long-running AI and transcription work out of API request workers.

See [Detailed Action Center changelog](docs/changelog/2026-08-09-action-center-functional.md).

## 2026-07-31 — Student experience and staff operations

### Student users

- Expanded onboarding into a complete, resumable enrollment-intake flow with
  housing and roommate preferences, support interests, emergency contacts,
  family permissions, review, signature, and deposit planning.
- Added clearer enrollment progress and optional follow-up summaries.
